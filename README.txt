BHOOTU BIRTHDAY WEBSITE
=======================

Files
-----
index.html  Complete self-contained birthday website.

How to open
-----------
1. Download and extract the ZIP (if using the ZIP).
2. Double-click index.html.
3. It opens in Chrome, Edge, Firefox, or another modern browser.

How to share it as a website link
---------------------------------
The HTML file is ready for static hosting. You can upload the folder to a static host
such as Netlify Drop, or put index.html in a GitHub repository and enable GitHub Pages.
After publishing, send her the public URL.

Customization
-------------
Open index.html in VS Code or any text editor.
- Change visible text by searching for the words you want to edit.
- Birthday date is November 2 and is calculated automatically for the next occurrence.
- The friendship date is shown as January 22, 2025.
- The nickname is Bhootu and her name is Namu.
- Colors and animations are in the <style> section.

No external libraries, images, fonts, or API keys are required.
